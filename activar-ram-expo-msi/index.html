Lectura clara: Windows ya ve toda tu RAM (los 48 GB), así que el Memory Remap no está roto. Lo que te falta es velocidad: tu kit es de 6000 pero está corriendo a 4800. Activar EXPO recupera esos 1200 MHz. No ganarás "más GB" — ganarás rendimiento.
⚠️ Antes de empezar — lee esto:
  • El primer arranque tras activar EXPO puede tardar 15–60 s con pantalla en negro (la placa "entrena" la memoria). Es normal, no apagues a la fuerza.
  • Si el PC no arranca tras 2–3 intentos, la placa revierte sola a valores seguros (o pon el jumper/botón Clear CMOS). No se daña nada.
  • Guarda tu trabajo y cierra programas: vamos a reiniciar.

Paso 1. Entrar a la BIOS

Reinicia y, mientras aparece el logo MSI, toca Supr (Delete) varias veces.

1

Pulsa Supr / Del repetidamente en el logo

Entrarás al EZ Mode (modo fácil) de la Click BIOS 5. Alternativa en Windows 11: Shift + reiniciar → Solucionar problemas → Opciones avanzadas → Configuración de firmware UEFI.

Pantalla de arranque — el momento para pulsar Supr/Del.

Paso 2. Activar A-XMP / EXPO en EZ Mode (la vía rápida)

En AMD, MSI llama al perfil A-XMP y al elegir el perfil verás la etiqueta EXPO. Está arriba a la izquierda del EZ Mode.

2

Haz clic en el interruptor A-XMP → elige Profile 1 (EXPO) · DDR5-6000

EZ Mode: activa el interruptor A-XMP y elige Profile 1 (EXPO). Verás DRAM Frequency saltar a 6000 MHz.
Si tu EZ Mode no muestra el recuadro A-XMP, no pasa nada: lo hacemos desde el menú avanzado en el Paso 3. Cualquiera de las dos vías sirve — con una basta.

Paso 3. Vía avanzada (menú OC) — equivalente

Pulsa F7 para pasar a Advanced Mode y entra a OC. Aquí también verificamos el Memory Remap (Opción 3).

3

OC → Extreme Memory Profile (A-XMP) → Enabled · Profile 1

Menú OC: A-XMP en Enabled · Profile 1 (Opción 1) y, más abajo, Memory Remap = Enabled (Opción 3, ya correcto en tu PC).
Opción 3 (Memory Remap): en tu B850 con Windows 11 de 64 bits ya viene activado — por eso Windows ve los 48 GB completos. Solo confirma que diga Enabled; no necesitas cambiar nada.

Paso 4. Guardar y reiniciar

4

Pulsa F10 → Save & Exit → Enter

Confirma Yes. Recuerda: el primer arranque puede tardar por el memory training. Paciencia.

Paso 5. Validar que funcionó (en Windows)

No basta con haberlo activado: hay que comprobar el efecto real. Dos formas, la 2ª es la fiable.

5

A) Administrador de tareas (rápido)

Ctrl+Shift+Esc → pestaña Rendimiento → Memoria. Debe decir Velocidad: 6000 MHz y 48.0 GB.

Administrador de tareas → Rendimiento → Memoria. Busca Velocidad: 6000 MHz.
Ojo con un detalle: Windows a veces reporta DDR "efectiva/2". Si ves 3000 MHz ahí, NO es error: 3000 × 2 (DDR) = DDR5-6000. Está bien. Por eso conviene la comprobación B.

B) CPU-Z (la prueba definitiva)

Descarga CPU-Z → pestaña Memory. En DRAM Frequency debe marcar ~3000 MHz (recuerda: ×2 = 6000). Si sigue en ~2400 MHz, EXPO NO quedó activo → vuelve al Paso 2.

CPU-Z → Memory. DRAM Frequency ≈ 3000 MHz confirma que corres a DDR5-6000. ✅
✅ Resumen de tu caso
  • Opción 1 (EXPO/A-XMP): este es tu cambio real — de 4800 a 6000 MHz. Pasos 2–4.
  • Opción 3 (Memory Remap): solo verificación; ya está activado y Windows ya usa tus 48 GB.
  • Ambas conviven sin conflicto. Ninguna borra datos ni daña el hardware.
