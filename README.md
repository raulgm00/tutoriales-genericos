## ✍️ Cómo agregar un tutorial nuevo

1. Crea una carpeta `nombre-del-tutorial/` con un `index.html` dentro.
2. Agrega la tarjeta correspondiente en el `index.html` de la raíz.
3. `git add . && git commit -m "nuevo tutorial" && git push`.

El sitio se actualiza solo en 1–2 minutos.
